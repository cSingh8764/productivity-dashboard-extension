# Productivity Dashboard Chrome Extension

A custom new tab Chrome extension with modular "islands" including:
- Search bar
- Task manager
- Calendar (in progress)

## Features
- Replace new tab with custom dashboard
- Persistent task list (localStorage)
- Clean modular UI

## How to Run
1. Clone the repo
2. Go to chrome://extensions/
3. Enable Developer Mode
4. Click "Load unpacked"
5. Select the project folder
